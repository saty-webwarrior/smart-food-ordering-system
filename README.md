# Smart Food Ordering System (College Canteen)

PBL project for Software Engineering (CMCA0303), MCA, NIET Greater Noida. Group G14.
SDG 9 - Industry, Innovation and Infrastructure.

A browser-based demo prototype of the system:

- **Student:** view the menu, build a cart, place an order and follow its status.
- **Canteen staff:** see incoming orders, move them through Placed, Accepted, Preparing, Ready and Completed, and mark menu items available or unavailable.
- **Admin report:** orders placed, orders completed, total sales and the most ordered items.

Open `index.html` in a browser, or use the GitHub Pages link. Data is stored only in the browser (localStorage).
